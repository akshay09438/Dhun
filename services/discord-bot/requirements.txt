# Prompt-DJ Discord bot - runtime dependencies.
#
# discord.py 2.7+ is REQUIRED, not merely preferred. Discord has deprecated voice gateway v4,
# which 2.5.x requests, and now closes those connections with code 4017 - the handshake completes,
# finds the media endpoint, then dies. It rolls out per voice server, so it presents as voice
# working once and then never again. 2.7 speaks v8.
#
# The earlier pin to <2.6 was based on a wrong reading: it assumed 2.6+ needed the native 'davey'
# package (Discord's end-to-end encryption), whose wheel wants a Rust toolchain this machine does
# not have. davey is a SOFT import - without it has_dave is False and voice works exactly as
# before, minus E2EE, which ordinary server voice channels do not use. Do not re-pin below 2.7.
discord.py>=2.7,<3
PyNaCl>=1.5,<1.6
httpx>=0.27,<1
