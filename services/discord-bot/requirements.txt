# Prompt-DJ Discord bot - runtime dependencies.
#
# VOICE DOES NOT WORK ON THIS MACHINE (Windows ARM64), and both roads are closed:
#
#   discord.py 2.5.x  requests voice gateway ?v=4, which Discord has RETIRED. Connections get as
#                     far as the media endpoint and are then closed with code 4017. Rolled out per
#                     voice server, so it looks like voice working once and then never again.
#   discord.py 2.6+   speaks ?v=8 and works, but raises
#                     "RuntimeError: davey library needed in order to use voice" the moment you
#                     connect. davey is Discord's audio E2EE and has NO distribution for win-arm64
#                     at all (pip: "from versions: none"); building it needs a Rust toolchain.
#
# It is NOT a soft dependency, despite the try/except ImportError in voice_state.py - that only
# controls whether E2EE is offered, and the connect path checks separately. Verified 2026-08-11 by
# upgrading and watching it raise.
#
# Staying on 2.7 regardless: everything else is current, and voice now fails instantly with a clear
# message instead of thirty seconds of doomed retries. Getting voice working means running the bot
# on an x86 machine or a small cloud box, where davey has wheels.
discord.py>=2.7,<3
PyNaCl>=1.5,<1.6
httpx>=0.27,<1
